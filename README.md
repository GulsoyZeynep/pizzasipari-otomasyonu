# 🍕 Pizza Otomasyon Sistemi

Bu proje, bir pizzacı işletmesinin sipariş süreçlerini, müşteri kayıtlarını ve ürün stoklarını dijital ortamda yönetebilmesi için geliştirilmiş bir masaüstü uygulamasıdır.

## 🚀 Özellikler
- **Sipariş Yönetimi:** Farklı boyut ve içeriklere göre dinamik fiyat hesaplama.
- **Müşteri Kayıt Sistemi:** Müşteri bilgilerinin takibi ve geçmiş siparişlerin listelenmesi.
- **Ürün & Stok Takibi:** Menüdeki pizzaların ve ek malzemelerin yönetimi.
- **Raporlama:** Günlük satış verilerinin takibi.

## 🛠 Teknik Veriler
- **Dil:** C#
- **Platform:** .NET Framework / .NET Core (Hangisini kullandıysanız)
- **Veritabanı:** MS SQL Server
- **Mimari:** Entity Framework (veya ADO.NET)
- **Tasarım:** Modern UI bileşenleri
